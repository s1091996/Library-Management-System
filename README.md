
## 1. 專案名稱與簡介（Project Title & Overview）

**Library Management System（圖書館管理系統）**

本專案是一套以 C 語言實作的主控台圖書館管理系統，用於處理圖書資料、學生帳號與借還書流程。

此專案模擬圖書館的基本營運情境，將圖書複本、借閱者與到期日資訊集中於程式中管理。程式在啟動時從文字檔載入圖書與學生資料，讓使用者透過指令進行操作。

系統可查詢館藏、驗證學生帳號、借書、還書、新增或刪除圖書，以及查看個人借閱資訊；並針對借閱上限、逾期與已借出的圖書套用相應規則。

## 2. 功能特色（Features）

- **文字檔資料載入：** 啟動時讀取 `Books.txt` 與 `Students.txt`，建立圖書、學生帳號與既有借閱資料。
- **帳號登入驗證：** 借書、還書與查詢個人借閱資訊前，會依學生 ID 與密碼驗證帳號。
- **館藏查詢：** 可依書名、作者或 ISBN 搜尋圖書，並顯示出版年份、版序、複本編碼與借閱狀態。
- **借書管理：** 以書名或 ISBN 加上複本編碼定位圖書；僅可借閱未被借出的複本。
- **借閱限制：** 每位學生最多同時借閱 3 本圖書；若有逾期紀錄，系統會拒絕新的借書操作。
- **到期日計算：** 新借閱資料以系統本機時間為借閱日，並計算 7 天後的到期日。
- **還書處理：** 還書後會清除圖書的借閱者與借閱日期資訊，並更新學生的借閱數量。
- **圖書維護：** 可新增圖書複本；刪除前會確認圖書存在且未處於借閱中。
- **借閱資訊檢視：** 登入後可查看目前借閱圖書的 ISBN、借閱日期與到期日。

## 3. 系統流程／架構（System Architecture）

```text
Books.txt、Students.txt
        ↓
程式啟動：載入圖書與學生資料
        ↓
使用者輸入指令（B / R / A / D / Q / I / P / E）
        ↓
對應功能處理與資料驗證
        ↓
更新記憶體中的圖書／學生借閱狀態
        ↓
主控台輸出處理結果
```

- `struct Book`：保存書名、作者、出版年份、版序、ISBN、複本編碼、借閱者與日期資訊。
- `struct Student`：保存學生 ID、密碼、目前借閱數量，以及最多 3 筆借閱圖書指標。
- `books` 與 `students`：分別為程式執行期間的圖書與學生資料陣列。
- 指令迴圈：由 `main()` 讀取單一指令，再呼叫借書、還書、查詢或維護函式。

## 5. 安裝與快速開始（Installation & Quick Start）

本專案只需具備可編譯 C 語言的編譯器（例如 GCC）。

1. 複製專案至本機。上傳 GitHub 後，請將下列 `<repository-url>` 替換為實際儲存庫網址：
   ```powershell
   git clone <repository-url>
   cd Project2
   ```
   
2. 確認 `Books.txt` 與 `Students.txt` 位於目前目錄。
3. 使用 GCC 編譯並執行 `Final.c`：

   ```powershell
   gcc Final.c -o LibraryManagement.exe
   .\LibraryManagement.exe
   ```

## 6. 使用範例（Usage / Examples）

程式啟動後會讀取資料檔，接著等待使用者輸入下列單一字母指令：

| 指令 | 功能 |
| --- | --- |
| `B` | 登入後借書 |
| `R` | 登入後還書 |
| `A` | 新增圖書 |
| `D` | 刪除圖書 |
| `Q` | 查詢圖書 |
| `I` | 登入後查詢個人借閱資訊 |
| `P` | 列出所有圖書 |
| `E` | 結束程式 |

### 範例：借閱圖書

1. 輸入 `B`。
2. 輸入 `Students.txt` 中存在的學生 ID 與正確密碼。
3. 輸入欲借閱圖書的書名或 ISBN。
4. 輸入該書的複本編碼。

系統會確認帳號、圖書是否存在、複本是否可借、學生目前借閱數是否已達 3 本，以及是否存在逾期借閱；通過後會顯示借閱成功與到期日。

例如，資料檔中包含 ISBN `0131118811`、複本編碼 `1` 的圖書時，可依序輸入：

```text
B
495713001
3001
0131118811
1
```

## 7. 限制與注意事項（Limitations / Notes）

- 圖書與學生資料以固定大小陣列管理，程式常數分別限制為最多 50 筆圖書與 50 位學生。
- 每位學生最多可同時借閱 3 本圖書。
